# Changelog

Releases are tagged `vX.Y.Z`. Update with `orca plugin update matiaz.pulse`.

## 0.2.0

- The Git box shows the CI result of the latest pushed commit when the branch has no pull request (`✓ checks passed`, `● checks running`, `✗ checks failed`). Click it to open that commit's checks on GitHub.

## 0.1.0

- First release: activity heatmap (GitHub contributions or Claude Code cost) with Claude plan limits, pull requests ranked by what they need from you with review, auto review and auto merge, and a Git box with stage, AI commit message, commit, pull, push and create PR.
